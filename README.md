# Persian Wikipedia Editor‌ Skill (دستیار ویکی‌نویسی ۴)

این مخزن شامل یک دستورالعمل جامع و مهارت برای هوش مصنوعی است که آن را به یک دستیار حرفه‌ای برای ترجمه، ویرایش، ویکی‌سازی و منبع‌دهی مقالات در ویکی‌پدیای فارسی تبدیل می‌کند. این پروژه فراتر از یک پرامپت است و به یک مهارت بهبود هوش مصنوعی تبدیل شده است که به سادگی می‌توانید آن را با کپی فایل .md در مدل هوش مصنوعی مورد نظرتان استفاده کنید.

## ویژگی‌ها
- دقت و وفاداری: جلوگیری از توهم (Hallucination) و ترجمه دقیق بدون حذف محتوا.
- ویکی‌سازی استاندارد: تنظیم خودکار پیوندهای درونی (`[[...]]`)، بخش‌بندی‌ها (`== ... ==`) و لیست‌ها.
- منبع‌دهی حرفه‌ای: تنظیم منابع با تگ `<ref>` و پشتیبانی از ارجاع‌های تکراری (`<ref name="..." />`) بدون ترجمه کردن متادیتاهای منبع.
- کنترل کیفیت: بررسی نام‌ها، تاریخ‌ها، لحن دانشنامه‌ای و قوانین مربوط به تصاویر.

## نحوه استفاده
کافیست محتوای فایل `fa-wikipedia-editor.md` را کپی کرده و به عنوان دستورالعمل سیستم (System Prompt) یا کاستوم اینستراکشن (Custom Instruction) در مدل‌های هوش مصنوعی (مثل ChatGPT، Claude یا Gemini) قرار دهید. سپس متن انگلیسی یا پیش‌نویس خود را برای ترجمه یا ویرایش به آن بسپارید.

## قوانین و محدودیت‌های استفاده (License & Terms of Use) **Important**
این پروژه برای کمک به بهبود مقالات ویکی‌پدیا و ترویج دانش آزاد طراحی شده است. با استفاده از این ابزار، شما می‌پذیرید که:
1. استفاده تجاری ممنوع است: حق فروش این دستورالعمل (Prompt) یا استفاده از آن در قالب سرویس‌های پولی (بدون کسب اجازه) را ندارید.
2. خرابکاری در ویکی‌پدیا خط قرمز است: استفاده از این ابزار برای تولید مقالات جعلی (Hoax)، اسپم، ربات‌های مخرب، و دور زدن یا نقض سیاست‌های ویکی‌پدیای فارسی اکیداً ممنوع است. کاربر موظف است خروجی‌ها را پیش از انتشار نهایی بازبینی کند.

## مشارکت
خوشحال می‌شوم اگر پیشنهاد یا اصلاحی برای بهبود این دستورالعمل دارید، از طریق Issue یا Pull Request مشارکت کنید.
